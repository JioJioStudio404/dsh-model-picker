# dsh-model-picker

DeepSeek Harness 对话输入框的模型选择器，改为逐级展开的级联菜单：服务商 › 模型 › 推理等级。服务商较多时，先选服务商，模型列表只显示该服务商的模型。

## 功能

- **级联展开**：悬停或点击「服务商」展开服务商列表；悬停或点击某个服务商展开其模型；有推理等级（包括开 / 关）的模型展开推理等级，选择等级即完成切换；没有推理等级的模型点击即切换
- **展开方向**：优先向右展开，右侧空间不足时向左展开；每级卡片与打开它的那一行对齐，并保持在窗口范围内
- **返回上一级**：已展开的各级卡片同时显示，可直接回到上一级改选；← 或 Esc 逐级关闭。窗口宽度不足 720px 时改为单张卡片逐级进入，顶部提供「返回」
- **服务商**：按 DeepSeek Harness 自带的顺序排列；每家显示上次使用的模型，未使用过的显示模型数量；超过 4 家时可按名称搜索；目录加载失败的服务商单独提示，并可重新加载。服务商名称以 DeepSeek Harness 的默认蓝色显示，与模型名称区分
- **模型与推理等级**：只显示所选服务商的模型，超过 4 个时可搜索；当前模型与等级带勾选标记，尚未使用的模型标注其默认等级
- **会话选项**：其他功能添加到模型菜单的会话选项（如 DeepSeek Harness 的「使用智能体团队」开关）显示在「推理等级」下方
- **按钮与键盘**：按钮外观与 DeepSeek Harness 自带的选择器一致；支持 ↑ ↓ ← → Enter Esc 操作
- 适用于 DeepSeek Harness 模型列表中的所有服务商，包括自带的服务商和其他插件提供的服务商；与自带选择器和 `/model` 使用同一份会话模型目录，在任一处切换，其他位置同步更新
- 不读写文件，不需要 Key；「上次使用」只保存在本机浏览器存储中

## 安装

需要 DeepSeek Harness 0.2.2 或更高版本，Node.js 24.9 或更高版本。

```bash
git clone https://github.com/JioJioStudio404/dsh-model-picker.git
dsh plugin --profile desktop add "/path/to/dsh-model-picker"
```

安装后重启 DeepSeek Harness。停用或卸载插件后，恢复 DeepSeek Harness 自带的模型选择器。

## 已知限制

- `/model` 命令的弹窗仍为 DeepSeek Harness 自带样式
